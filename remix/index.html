8 내보내기

아이폰은 📱 사진첩에 저장을 누른 뒤 공유 시트에서 '비디오 저장'을 고르면 사진첩(앨범)에 바로 저장돼요.

영상은 30fps 고정으로 한 장씩 인코딩해요. 슬라이드처럼 끊기지 않고 사진첩에서도 부드럽게 재생돼요.

사용법 · 팁
  1. 영상을 올리면 목소리(옹알이) 구간을 자동으로 찾아요. 맞지 않으면 다시 분석이나 균등 분할.
  2. 비트는 내장 신스 4종에서 고르거나, 내 음원/화면녹화 영상의 원하는 구간만 잘라 쓸 수 있어요.
  3. 구성에서 총 길이와 구간(인트로·드롭·브레이크)별 마디를 직접 조정하세요.
  4. 포맷에서 Ver.1/풀스크린/화이트/네온을 고르거나 내 포맷을 저장해요.
