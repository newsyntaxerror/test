# 다인이 리믹스 스튜디오

아기(다인) 영상을 올리면 **목소리(옹알이) 구간을 자동으로 찾아** 비트에 맞춰 컷 편집·리믹스하는 모바일 퍼스트 웹앱(PWA)입니다.
서버 없이 브라우저 안에서만 동작하며(Web Audio / Canvas / WebCodecs / MediaRecorder), 업로드한 영상은 어디에도 전송되지 않습니다.

- 주소: https://newsyntaxerror.github.io/studio/remix/

## 기능

1. **영상 → 목소리 자동 추출**
   - MP4/MOV/WebM(또는 오디오) 업로드 → `decodeAudioData`로 디코딩
   - **아이폰 기본 동영상(.mov QuickTime, H.264/HEVC + AAC) 지원(v1.1)**: `decodeAudioData`가 실패하면 `js/analyze.js`의 순수 JS ISO BMFF 디먹서가 `moov→trak→mdia→hdlr('soun')→minf→stbl`(stsd/esds·stsc·stsz·stco/co64)을 해석해 오디오만 뽑아냅니다. AAC는 ADTS 헤더(또는 최소 MP4 재포장)로, `lpcm/sowt/twos`는 WAV로 디코딩하고, `File.slice()`로 샘플 구간만 읽어 100MB+ 영상도 가볍게 처리합니다.
   - 프리엠퍼시스 에너지 피크 감지로 최대 12개 구간 자동 슬라이스
   - 구간별 미리듣기 · 사용 on/off · 시작점 50ms 미세조정, 균등 분할 백업
2. **배경 비트 3가지 소스**
   - 내장 DSP 신스 4종(테크노 140 / 하우스 128 / 트랩 145 / Lo-fi 90) + BPM 90~160
   - 내 음원·화면녹화 영상 업로드(영상이면 오디오만 자동 추출) + **시작~끝 구간 선택** + BPM 추정/수동 + 박자 오프셋
   - 유튜브 링크(실험실): Cobalt 호환 API/프록시 시도, 차단 시 안내
3. **구성 · 길이**
   - 출력 길이 프리셋 10/15/20/30/45/60초 + 초·마디 직접 입력
   - 인트로 / 드롭 / 브레이크 / 아웃트로 구간별 마디·초 지정, 목소리·비트 on/off
4. **자동 비트싱크 영상 편집**
   - **1배속 부드럽게 맞추기(기본, v1.2)**: 원본 영상을 1.0배속 그대로 이어 재생하고, 영상이 출력보다 짧으면 자연 루프로 채워 음원 길이에 정확히 맞춥니다. 드롭 진입에서만 영상 처음부터 다시 시작해 비트와 맞추며, 녹화 중에는 매 프레임 시킹하지 않고 0.25초 이상 어긋날 때만 보정해 끊김이 없습니다(슬로우모션 없음).
   - **비트컷**: 목소리 피크를 소스로 비트 경계에서 자동 점프컷(컷 길이 1박~2마디)
   - 브레이크다운은 컷 없이 자연 재생, 3중 video 엘리먼트 프리시킹으로 끊김 없는 컷
   - 구간에서 **⚡ 바로 하이라이트**: 인트로를 빼고 0.0초부터 드롭으로 시작(총 길이 유지, `기본 구성`으로 복귀)
5. **영상 효과 편집(v1.3)**
   - **✨ 알아서 편집하기**: 장르·BPM에 맞춰 줌 펀치·비트 플래시·쉐이크·색감·🪩 싸이키 조명·테두리·컷 길이를 자동 세팅(테크노/하우스 약, 트랩 강, Lo-fi 끔 · 150BPM 이상은 한 단계 위)
   - **🎛️ 직접 편집하기**: 줌 펀치(끔/약/중/강) · 비트 플래시(끔/약/중/강) · 비트 쉐이크(끔/약/강) · **🪩 싸이키 조명(끔/약/강)** · 색감 필터(원본/선명하게/빈티지 웜/클럽 네온/흑백) · 모서리·테두리 비트 반응
   - **🪩 싸이키 조명(v1.3)**: 박자마다 핑크 `#FF2A85` · 시안 `#00F5D4` · 바이올렛 `#8B5CF6` · 네온옐로우 `#FFE600` 조명이 교차. 그라데이션 스포트라이트 + 컬러 오버레이(`color`/`screen`/`overlay` 합성)로 은은하게 색을 입히고, 테두리 쪽에서 도는 조명이 비트마다 번쩍입니다. 밝기(luminance)를 유지하는 합성만 써서 아이 얼굴을 가리지 않고, 영상 밖 배경에도 옅은 빛이 새어 나옵니다.
   - 미리보기와 저장 영상(Canvas)에 동일하게 적용
6. **출력 포맷**
   - 기본 `Ver.1 다인이네`(1080×1920 검정, 중앙 940×1000, 상단 2줄 후킹+형광핑크 `#FF2A85`, 하단 치즈냥이+`다인이네`)
   - 풀스크린 9:16 / 화이트 미니멀 / 클럽 네온 EDM
   - 배경·강조색·로고(치즈냥이/검은 강아지/내 이미지)·배지 문구·글자 크기 조정 후 **내 포맷 저장**(localStorage)
6. **내보내기(v1.3: 30fps 고정 인코딩)**
   - **WebCodecs 고정 30fps 렌더(우선)**: 1/30초 타임스텝마다 원본 `<video>`를 해당 시점으로 seek해 캔버스에 그린 뒤 `VideoEncoder`(H.264) + `AudioEncoder`(AAC, 미지원 시 Opus)로 한 장씩 인코딩하고 내장 `js/mp4-muxer.js`로 MP4를 만듭니다. 프레임 드랍 0% · CFR 30fps라 아이폰 사진첩에서도 슬라이드처럼 끊기지 않습니다(seek 무한 대기 방지 120ms 타임아웃, 키프레임 2초).
   - **폴백**: WebCodecs/코덱 미지원 브라우저는 기존 `MediaRecorder` 실시간 녹화(MP4 지원 시 MP4, 아니면 WebM)로 자동 전환. 폴백에서도 프레임 드랍을 줄이도록 렌더 루프의 DOM 갱신을 200ms에 1번만 하고, 숨긴 video 엘리먼트를 `position:fixed;left:-9999px;width:2px`로 DOM에 붙여 iOS 백그라운드 디코딩 스로틀링을 피합니다.
   - **저장 화질 선택(v1.2)**: `720×1280`(모바일 기본·4Mbps·끊김 적음) / `1080×1920`(6Mbps 고화질)
   - `OfflineAudioContext` 렌더 → 48kHz 16bit WAV (iOS 대비)
   - 썸네일 JPG
   - **📱 사진첩에 저장(v1.2)**: Web Share API(`navigator.share({ files })`)로 iOS 공유 시트를 띄워 `비디오 저장` 한 번에 사진첩에 저장. 미지원/실패 시 파일 다운로드로 자동 대체, 공유 시트를 닫으면 조용히 무시.

## 파일

- `index.html`, `css/app.css`
- `js/app.js` (UI·재생·내보내기), `js/draw.js` (Canvas 레이아웃·효과), `js/encode.js` (30fps WebCodecs 인코딩), `js/mp4-muxer.js` (내장 MP4 먹서, MIT), `js/dsp.js` (신스·WAV), `js/analyze.js` (구간 감지·BPM·MOV/MP4 오디오 디먹서), `js/arrange.js` (타임라인·컷), `js/formats.js` (포맷 프리셋), `js/yt.js`
- `assets/` 로고 2종 + Pretendard ExtraBold 서브셋, `manifest.json`, `sw.js`, `icons/`

## 참고

- 첫 방문 후 오프라인에서도 실행됩니다(SW 캐시). 새 버전 배포 시 `sw.js`의 `VERSION`을 올리세요.
- 미리보기는 실시간 재생, 30fps 내보내기는 길이의 약 2~6배(기기·영상에 따라) 걸립니다. WebCodecs가 없는 브라우저는 실시간(길이만큼) 녹화로 떨어집니다.
