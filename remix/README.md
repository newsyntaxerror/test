# 옹알이 리믹스

아기(다인) 영상을 올리면 **목소리(옹알이) 구간을 자동으로 찾아** 비트에 맞춰 컷 편집·리믹스하는 모바일 퍼스트 웹앱(PWA)입니다. 앱 이름은 **옹알이 리믹스**이고, 영상 안의 기본 포맷/배지는 `Ver.1 다인이네`로 남아 있습니다.
서버 없이 브라우저 안에서만 동작하며(Web Audio / Canvas / WebCodecs / MediaRecorder), 업로드한 영상은 어디에도 전송되지 않습니다.

- 주소: https://newsyntaxerror.github.io/studio/remix/

## 기능

1. **영상 → 목소리 자동 추출**
   - MP4/MOV/WebM(또는 오디오) 업로드 → `decodeAudioData`로 디코딩
   - **아이폰 기본 동영상(.mov QuickTime, H.264/HEVC + AAC) 지원(v1.1)**: `decodeAudioData`가 실패하면 `js/analyze.js`의 순수 JS ISO BMFF 디먹서가 `moov→trak→mdia→hdlr('soun')→minf→stbl`(stsd/esds·stsc·stsz·stco/co64)을 해석해 오디오만 뽑아냅니다. AAC는 ADTS 헤더(또는 최소 MP4 재포장)로, `lpcm/sowt/twos`는 WAV로 디코딩하고, `File.slice()`로 샘플 구간만 읽어 100MB+ 영상도 가볍게 처리합니다.
   - 프리엠퍼시스 에너지 피크 감지로 최대 12개 구간 자동 슬라이스
   - 구간별 미리듣기 · 사용 on/off · 시작점 50ms 미세조정, 균등 분할 백업
2. **배경 비트 3가지 소스**
   - 내장 DSP 신스 4종(테크노 140 / 하우스 128 / 트랩 145 / Lo-fi 90) + BPM 90~160
   - 내 음원·화면녹화 영상 업로드(영상이면 오디오만 자동 추출) + **시작~끝 구간 선택** + BPM 추정/수동 + 박자 오프셋
   - 유튜브 링크(실험실): Cobalt 호환 API/프록시 시도, 차단 시 안내
3. **구성 · 길이**
   - 출력 길이 프리셋 10/15/20/30/45/60초 + 초·마디 직접 입력
   - 인트로 / 드롭 / 브레이크 / 아웃트로 구간별 마디·초 지정, 목소리·비트 on/off
4. **자동 비트싱크 영상 편집**
   - **🎯 음원 싱크 믹싱(기본, v1.6)**: 음악에 실제로 섞인 **옹알이 조각(voiceEvents)** 을 기준으로 영상을 붙입니다. 조각마다 `srcStart = bufStart`, `rate = 조각 배속`인 `sync` 샷을 만들어, 스터터·반복·드래그·그리드 리믹스로 옹알이가 점프할 때마다 화면 속 입모양·표정도 **같은 원본 시점으로 정확히 점프·반복**합니다. 조각 사이 빈 구간은 직전 화면(조각이 끝난 시점)에서 1배속으로 자연스럽게 이어 재생해 멈추지 않고, 긴 빈 구간은 마디 경계에서 자연 재생 ↔ 표정 하이라이트 컷을 번갈아 넣어 비트에 맞춰 움직입니다. 미리보기 `playbackRate`·시킹과 30fps MP4 `sourceTimeAt`이 같은 식(`srcStart + (v-t0)*rate`, 영상 길이 루프)을 써서 **미리보기 = 저장 영상**입니다.
   - **1배속 부드럽게 맞추기(v1.2)**: 원본 영상을 1.0배속 그대로 이어 재생하고, 영상이 출력보다 짧으면 자연 루프로 채워 음원 길이에 정확히 맞춥니다. 드롭 진입에서만 영상 처음부터 다시 시작해 비트와 맞춥니다(슬로우모션 없음).
   - **비트 컷**: 목소리 피크를 소스로 비트 경계에서 자동 점프컷(컷 길이 1박~2마디). v1.6부터 모든 샷이 `rate: 1`로 흘러 정지 화면이 되지 않습니다.
   - 브레이크다운은 컷 없이 자연 재생, 3중 video 엘리먼트 프리시킹으로 끊김 없는 컷
   - 구간에서 **⚡ 바로 하이라이트**: 인트로를 빼고 0.0초부터 드롭으로 시작(총 길이 유지, `기본 구성`으로 복귀)
5. **영상 효과 편집(v1.3)**
   - **✨ 알아서 편집하기**: 장르·BPM에 맞춰 줌 펀치·비트 플래시·쉐이크·색감·🪩 싸이키 조명·테두리·컷 길이를 자동 세팅(테크노/하우스 약, 트랩 강, Lo-fi 끔 · 150BPM 이상은 한 단계 위)
   - **🎛️ 직접 편집하기**: 줌 펀치(끔/약/중/강) · 비트 플래시(끔/약/중/강) · 비트 쉐이크(끔/약/강) · **🪩 싸이키 조명(끔/약/강)** · 색감 필터(원본/선명하게/빈티지 웜/클럽 네온/흑백) · 모서리·테두리 비트 반응
   - **🪩 싸이키 조명(v1.3)**: 박자마다 핑크 `#FF2A85` · 시안 `#00F5D4` · 바이올렛 `#8B5CF6` · 네온옐로우 `#FFE600` 조명이 교차. 그라데이션 스포트라이트 + 컬러 오버레이(`color`/`screen`/`overlay` 합성)로 은은하게 색을 입히고, 테두리 쪽에서 도는 조명이 비트마다 번쩍입니다. 밝기(luminance)를 유지하는 합성만 써서 아이 얼굴을 가리지 않고, 영상 밖 배경에도 옅은 빛이 새어 나옵니다.
   - 미리보기와 저장 영상(Canvas)에 동일하게 적용
6. **출력 포맷**
   - 기본 `Ver.1 다인이네`(1080×1920 검정, 중앙 940×1000, 상단 2줄 후킹+형광핑크 `#FF2A85`, 하단 치즈냥이+`다인이네`)
   - 풀스크린 9:16 / 화이트 미니멀 / 클럽 네온 EDM
   - 배경·강조색·로고(치즈냥이/검은 강아지/내 이미지)·배지 문구·글자 크기 조정 후 **내 포맷 저장**(localStorage)
6. **내보내기(v1.4: 30fps 고정 + iOS 17/18 하이브리드 오디오)**
   - **WebCodecs 고정 30fps 렌더(우선)**: 1/30초 타임스텝마다 원본 `<video>`를 해당 시점으로 seek해 캔버스에 그린 뒤 `VideoEncoder`(H.264)로 한 장씩 인코딩하고 내장 `js/mp4-muxer.js`로 MP4를 만듭니다. 프레임 드랍 0% · CFR 30fps라 아이폰 사진첩에서도 슬라이드처럼 끊기지 않습니다(seek 무한 대기 방지 120ms 타임아웃, 키프레임 2초).
   - **오디오 A(경로 A)**: `AudioEncoder`가 있으면(v1.3 방식) 48kHz 믹스를 AAC(없으면 Opus)로 직접 인코딩합니다.
   - **오디오 B — iOS 17/18 하이브리드(경로 B, v1.4)**: iOS Safari 17/18은 `VideoEncoder`는 있지만 `AudioEncoder`(AAC)가 없습니다. 이때 실시간 `MediaRecorder` 전체 녹화(12fps)로 떨어지지 않고, ① 영상은 위 방식대로 고정 30fps `VideoEncoder`로 인코딩하고 ② 소리는 완성된 48kHz 믹스를 `MediaRecorder`에 **오디오 스트림만**(`MediaStreamAudioDestinationNode`, 영상 트랙 없음) 연결해 `audio/mp4`(AAC)로 녹음한 뒤 ③ 그 MP4 컨테이너의 `moov/moof`를 순수 JS로 파싱해 AAC 샘플과 `esds` AudioSpecificConfig를 꺼내 `muxer.addAudioChunkRaw()`로 비디오와 한 파일로 합칩니다. 결과는 **309프레임 @30fps (iOS 하이브리드)** 로 표시됩니다. 오디오 추출이 실패하면 무음이라도 30fps 영상으로 저장하고 안내합니다.
   - **폴백**: WebCodecs/코덱 미지원 브라우저는 기존 `MediaRecorder` 실시간 녹화(MP4 지원 시 MP4, 아니면 WebM)로 자동 전환. 폴백에서도 프레임 드랍을 줄이도록 렌더 루프의 DOM 갱신을 200ms에 1번만 하고, 숨긴 video 엘리먼트를 `position:fixed;left:-9999px;width:2px`로 DOM에 붙여 iOS 백그라운드 디코딩 스로틀링을 피합니다.
   - **저장 화질 선택(v1.2)**: `720×1280`(모바일 기본·4Mbps·끊김 적음) / `1080×1920`(6Mbps 고화질)
   - `OfflineAudioContext` 렌더 → 48kHz 16bit WAV (iOS 대비)
   - 썸네일 JPG
   - **📱 사진첩에 저장(v1.2)**: Web Share API(`navigator.share({ files })`)로 iOS 공유 시트를 띄워 `비디오 저장` 한 번에 사진첩에 저장. 미지원/실패 시 파일 다운로드로 자동 대체, 공유 시트를 닫으면 조용히 무시.
7. **목소리 음역 필터 · 구간 미리듣기 · 캡컷 타임라인(v1.5)**
   - **음역 필터**: `전체 목소리` / `👶 아기 고음 위주`. 아기 고음 모드는 Web Audio `BiquadFilter` **highpass 320Hz**(성인 저음 감쇄) + **peaking 700Hz −9dB**(저역 웅웅 담음)를 미리듣기·오프라인 믹스·MP4 오디오에 똑같이 적용합니다(실측 60~160Hz −16.6dB).
   - **구간별 `▶` 듣기 / 빼기**: 목소리 구간마다 `▶`를 누르면 그 구간 원본(필터 적용)만 바로 들리고, 다른 구간을 누르면 이전 재생은 자동으로 멈춥니다(`■`로 정지). `넣음/빠짐` 버튼으로 어른 목소리가 섞인 구간을 즉시 빼면 흐리게 표시되고 믹스·타임라인 배치에서 바로 빠집니다.
   - **🎛️ 캡컷 스타일 멀티트랙 타임라인**: 위 트랙 `🎙️ 옹알이`(조각 블록) + 아래 트랙 `🎵 비트/배경 음원`. 블록을 **포인터(터치)로 밀어** 위치를, **오른쪽 가장자리**를 끌어 길이를 바꾸고, 선택한 조각은 **시작·길이·볼륨 슬라이더**로 미세 조절합니다. 트랙 전체 시작 오프셋·볼륨, 비트 트랙의 시작·사용 길이·볼륨·페이드 인/아웃도 슬라이더로 조절합니다(`pointerdown/move/up` + 보조 range 슬라이더, `touch-action:none`으로 아이폰 Safari 드래그 대응).
   - **재생선(플레이헤드)**: 눈금/레인을 눌러 위치를 옮기고 `▶ 타임라인 듣기`로 그 지점부터 오디오 믹스를 미리 들어봅니다. 미리보기 재생 중에도 재생선이 함께 움직입니다.
   - **내보내기 100% 반영**: 타임라인 배치는 `scheduleMix` 한 곳에서 처리해 실시간 미리듣기·WAV·30fps MP4 오디오가 완전히 같은 결과를 냅니다(플레이헤드 시작 재생은 `from` 오프셋으로 같은 스케줄러 사용).
   - 손으로 옮긴 배치는 `localStorage`에 저장되고 `🔄 자동 배치`로 언제든 원래 자동 배치로 돌아갑니다.
   - **미리듣기 단일 재생**: `내 음원`의 `이 구간 듣기`, 구간 `▶`, 타임라인 듣기, 전체 미리보기가 모두 `stopAllPreviewAudio()`를 먼저 호출해, 연속으로 눌러도 소리가 겹치지 않고 항상 마지막 하나만 납니다.
8. **내 음원(가져온 노래) 리믹스 엔진(v1.5)**
   - **첫 박 자동 감지**: 선택 구간의 온셋(소리가 터지는 지점)을 5ms 단위로 훑어 BPM 그리드와 가장 잘 맞는 다운비트 오프셋을 찾아 `박자 시작`에 자동 적용합니다(`detectGridOffset`). 신뢰도가 표시되고 `🎯 첫 박 자동`으로 다시 맞출 수 있어요. 추정 BPM도 자동 적용되어, 노래와 컷이 어긋나지 않습니다.
   - **박자 그리드 리믹스 패턴**: 가져온 노래 모드에서는 원본을 통으로 틀지 않고, 옹알이 조각을 그리드에 맞춰 썰어 넣습니다 — 드롭은 1·3박 → 한 박씩 → 마지막 마디 8분음표 하이퍼 스터터, 브레이크는 한 마디에 길게, 인트로는 시작 한 번 + 드롭 직전 빌드업 스터터. 조각은 항상 슬롯 길이 안에서 잘려 원본이 그대로 흐르지 않습니다(끄기 스위치 있음).
   - **사이드체인 덕킹**: 옹알이가 터지는 순간마다 가져온 노래를 -5dB(0~10dB 조절) 눌렀다가 0.16초에 걸쳐 되돌려, 옹알이와 노래가 한 트랙처럼 붙습니다.
   - **트림 슬라이더 터치 드래그**: 두 손잡이 슬라이더는 트랙 아무 곳이나 손가락으로 눌러 가까운 손잡이를 끌 수 있습니다(`pointerdown/move`, `touch-action:none`).

## 파일

- `index.html`, `css/app.css`

## 참고

- 첫 방문 후 오프라인에서도 실행됩니다(SW 캐시). 새 버전 배포 시 `sw.js`의 `VERSION`을 올리세요.
- 미리보기는 실시간 재생, 30fps 내보내기는 길이의 약 2~6배(기기·영상에 따라) 걸립니다. iOS 17/18(iOS 하이브리드)은 소리를 실시간으로 한 번 녹음하므로 길이만큼이 더 걸립니다. WebCodecs가 없는 브라우저는 실시간(길이만큼) 녹화로 떨어집니다.
