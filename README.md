# 👥 우리끼리 — 친구끼리만 위치·채팅

광고 없는, **서로 친구가 된 사람끼리만** 쓰는 위치 공유 + 1:1 채팅 웹앱(PWA)입니다.
방(room) 코드 대신 **내 고유 친구 코드**로 사람을 맺고, 친구 사이에서만 위치·배터리·머문 시간·이동 속도·동선과 채팅이 보입니다.
**앱 설치 없이** 링크만 열면 되고, 아이폰은 사파리에서 '홈 화면에 추가'로 앱처럼 쓸 수 있어요.

![지도 화면](./preview.png)

> **배포된 주소 (2026-11-23)**: <https://newsyntaxerror.github.io/our-map/>

## 1. 어떻게 쓰나요

1. **아이디 + 비밀번호로 시작** — 이메일 없이 닉네임·아이디·비밀번호(4자 이상)만 정하면 내 고유 **친구 코드**(예: `JT7-RBUE`)가 만들어집니다.
   - **자동 로그인**(기본 켜짐)을 켜 두면 로그인 열쇠를 `localStorage` + 쿠키(1년) + `IndexedDB` 세 곳에 남겨, 사파리·홈 화면 앱이 저장소를 비워도 다시 열면 자동으로 들어갑니다. 끄면 이번 탭(`sessionStorage`)에만 남아 브라우저를 닫으면 풀립니다.
   같은 아이디로 다른 기기·다른 브라우저에서 로그인하면 친구·채팅·동선이 그대로 보여요.
   열쇠는 `localStorage`와 쿠키(1년)에 함께 저장되어, 사파리가 저장소를 비워도 다시 로그인만 하면 됩니다.
   - 이미 쓰던 사람: 앱 위쪽 **아이디 만들기** 안내(또는 내 프로필 → 내 계정)를 누르면 **지금 친구·채팅을 그대로 둔 채** 아이디만 붙습니다.
   - 내 프로필 → 내 계정에서 **로그아웃 / 계정 전환**을 할 수 있어요.
2. **친구 맺기**
   - 내 친구 코드/초대 링크(`?add=내코드`)를 복사해 보내기 (상단 공유 버튼, `친구 추가` 창, `초대 링크 복사` 칩)
   - 받은 코드를 `친구 추가`에 입력해 요청 보내기, 또는 초대 링크로 들어오면 시작과 동시에 요청이 갑니다.
   - 요청을 받으면 시트 위에 **빨간 뱃지**와 함께 요청 목록이 뜨고 **[수락] / [거절]** 할 수 있어요. (서로 동시에 요청하면 바로 친구가 됩니다.)
3. **친구가 되면** 지도에 서로의 실시간 위치, 배터리(⚡/🔋), 머문 시간, 이동 속도, 실시간 이동 경로선이 보입니다.
   핀이나 카드를 누르면 상세 시트가 열리고, **[이동 동선 보기]** 를 누르면 지도 전체에 그 사람의 동선이 펼쳐집니다.
   - **하단 메뉴에서 친구 카드(아이콘)를 누르면** 지도가 그 친구에게 부드럽게 이동해 위쪽 지도 가운데에 핀이 오고, 상세 시트가 함께 열립니다.
   - 출발 지점 · 머문 곳(번호 + 머문 시간) · 현재 위치 핀이 지도에 찍히고, 선에는 이동 방향 화살표가 붙습니다.
   - **한 지점에 5분 이상 머문 곳만** '체류'로 끊어 저장합니다(신호 대기처럼 5분 미만은 이동 구간에 포함). 체류는 시작 시각과 끝 시각을 모두 기록해, 머문 동안에도 기록이 끊기지 않습니다.
   - 체류 핀·팝업·타임라인에는 OpenStreetMap 으로 찾은 **장소명 · 업종**(예: `스타벅스 · 카페`, `NC백화점 · 쇼핑몰`, `한마음삼성 아파트 · 집/아파트`, `강서로 · 주변`)이 함께 표시됩니다. 찾은 장소는 30일 캐시합니다.
   - 핀을 누르면 시각·체류 시간·다음 이동 거리/속도가 뜨고, 위쪽 동선 바에서 **[타임라인]** 을 열면
     구간별 이동/체류 내역이 나옵니다(항목을 누르면 해당 핀으로 지도가 이동). **[동선 닫기]** 로 돌아옵니다.
   - PC·와이파이 환경에서 정밀 위치가 안 잡히면 네트워크 위치로 자동 재시도합니다.
   - **프로필 사진** — 내 정보에서 사진을 고르면 정사각으로 잘라 180×180 JPEG(약 15~30KB)로 줄여 저장하고, 지도 핀·친구 목록·그룹 멤버 칩·채팅 화면에 원형으로 보여요. **[기본으로]** 를 누르면 이니셜로 돌아갑니다.
   - **자동 상태** — 내가 상태 문구를 비워 두면, 5분 이상 머문 곳의 장소·업종을 찾아 `☕ 스타벅스 · 12분째` 처럼 대신 보여줍니다(직접 쓴 상태가 있으면 그것이 우선).
   - **이모지 콕** — 친구 상세 시트의 `👋 ❤️ ☕ 📍 😆` 를 누르면 상대 화면에 이모지가 날아다니고 "OO님이 👋 보냈어요!" 알림이 떠요(같은 사람에게 3초에 한 번).
4. **지도 화면** — 오른쪽 아래 **⌖ 내 위치** 버튼을 누르면 내 위치로 부드럽게 이동·확대되고 위치도 새로 받아옵니다.
   - **지도 스타일 4종** — 오른쪽 아래 **레이어 버튼**을 누르면 **파스텔(Voyager, 기본) · 미니멀(Positron) · 다크(Dark Matter) · 기본(OSM)** 중에서 바로 고를 수 있습니다. 고른 스타일은 기기에 저장되어 다음에 열 때도 유지되고, 다크 지도에서는 핀 이름·상태·저작권 표시를 어두운 배경에 맞게 바꿔 잘 보이게 합니다.
   - **친구 탭**에서는 지도에 **나와 1:1 친구들만**, **그룹 탭**에서는 **나와 고른 그룹(카드에 '지도 표시 중')의 멤버들만** 보입니다. 그룹에 없는 친구는 그룹 지도에서 빠지고, 친구가 아닌 그룹원은 친구 지도에서 빠집니다. 채팅 탭으로 가면 직전에 보던 지도가 그대로 남아요.
   - 상단 시트의 **[⌄ 메뉴]** 로 하단 시트를 접어 지도를 넓게 볼 수 있고, 접으면 아래에 **[^ 메뉴 열기]** 알약이 남아 언제든 다시 엽니다(안 읽은 채팅·받은 요청 수 표시).
   - 앱 버전은 **내 정보 맨 아래**와 시작 화면 아래에 표시됩니다(지금은 v22).

5. **채팅** — 상세 시트의 **[채팅]** 버튼 또는 하단 **채팅 탭**에서 1:1 대화. 새 메시지는 친구 카드와 채팅 탭에 빨간 숫자로 표시되고, 대화를 열면 읽음 처리됩니다.
   - **카톡식 안 읽은 숫자** — 내가 보낸 말풍선 **왼쪽에 노란 숫자**가 뜹니다. 1:1은 상대가 읽기 전까지 `1`, 상대가 대화를 열면 바로 사라지고 시간 옆에 `읽음`이 붙어요. 그룹은 아직 안 읽은 멤버 수(`3 → 2 → 1 → 사라짐`)이고, 한 명 읽을 때마다 바로 줄어듭니다.
   - **알림** — 새 채팅이 오거나 친구·그룹 멤버가 오프라인에서 온라인으로 바뀌면 화면 위쪽에 알림 배너가 뜨고(누르면 그 대화·프로필로 이동), 브라우저 알림을 허용한 기기에서는 알림음·진동과 함께 알림이 옵니다. 알림 권한은 **내 정보 → 알림 → [알림 켜기]** 에서 켜요.
   - **개인별 알림 끄기** — 친구 상세 시트의 **[🔔 알림 켜짐]** 을 누르면 그 사람의 새 채팅·온라인·근처 알림이 모두 꺼지고, 다시 누르면 켜져요(기기에 저장). 그룹 카드의 🔔 버튼으로 그룹 알림만 끌 수도 있습니다.
   - **근처 알림** — 친구나 그룹 멤버가 **300m 안**으로 들어오면 `📍 OO 님이 근처(약 150m)에 있어요!` 배너가 뜨고, 브라우저 알림을 허용한 기기에서는 알림음·진동과 함께 알림이 옵니다. 같은 사람은 **30분에 한 번**만, **500m 넘게 멀어졌다가** 다시 들어오면 또 알려요. 알림을 끈 사람은 근처 알림도 오지 않습니다.

6. **그룹** — 하단 **그룹** 탭에서 **그룹 만들기**(그룹명 입력 → 초대 코드·초대 링크 `?group=코드` 자동 발급) 또는 **초대 코드로 참여**를 눌러 들어갑니다.
   - 한 그룹에 들어가면 **서로 1:1 친구가 아니어도** 그룹 멤버끼리 지도에서 서로의 위치·배터리·머문 시간(체류)·이동 동선을 볼 수 있어요(그룹 밖 사람에게는 보이지 않음).
   - **[단체 채팅]** 으로 그룹 멤버 모두와 대화할 수 있고, 받은 초대 링크(`?group=코드`)로 들어오면 로그인 후 그룹에 바로 참여돼요.
   - 내 말풍선 옆 **노란 숫자**는 아직 읽지 않은 멤버 수예요(카카오톡처럼 3명 중 2명이 안 읽었으면 2 → 한 명이 읽으면 1 → 모두 읽으면 사라짐).
   - 그룹 카드의 **[내 위치 공개/숨김]** 스위치로 그 그룹에서만 내 위치·동선을 잠깐 숨길 수 있어요(다른 그룹·1:1 친구에게는 그대로). 숨긴 동안에도 그룹 채팅은 됩니다.
   - 기본 화면은 지금처럼 **1:1 친구**가 기본이고, 그룹은 옆 탭에서 고를 때만 펼쳐집니다.

기존 기능은 그대로입니다: 고스트 모드 없음, 실시간 경로선, 경로 히스토리 저장, iOS 배터리 직접 입력, 위치를 못 받으면 서울시청 기준 좌표로 표시.

## 2. 친구·가족과 실제로 쓰기 (약 10분)

### ① Supabase 프로젝트 만들기
1. https://supabase.com → 무료로 시작(카드 등록 없음)
2. New project → 이름·비밀번호·지역(Seoul) 선택

### ② 표 만들기
Supabase 대시보드 → **SQL Editor** → `supabase_schema.sql` 내용을 통째로 붙여넣고 **RUN**.
아래가 한 번에 만들어집니다.

| 표 | 내용 |
| --- | --- |
| `friend_profiles` | 프로필(닉네임·친구 코드·아이디·비밀번호 해시·비밀 토큰·색·프로필 사진) |
| `friend_locations` | 현재 위치·배터리·속도·체류 시작 시각 |
| `friend_history` | 이동 경로 좌표(동선·타임라인용) |
| `friendships` | 친구 요청/수락 상태(`pending`·`accepted`·`declined`) |
| `friend_messages` | 1:1 메시지와 읽은 시각 |
| `friend_pokes` | 이모지 콕(찌르기)과 확인 시각 |
| `auth_sessions` | 아이디 로그인으로 발급된 세션 토큰(1년, 로그아웃 시 폐기) |
| `share_groups` · `group_members` · `group_messages` | 그룹(초대 코드)·그룹 멤버(위치 숨김·마지막 읽은 시각)·그룹 단체 채팅 |

표는 **직접 읽고 쓸 수 없게 잠그고**(RLS + 권한 회수), 아래 서버 함수로만 주고받습니다.
`friend_bootstrap`, `friend_feed`, `friend_request`, `friend_respond`, `friend_publish`, `friend_log_point`,
`friend_history`, `friends_history_since`, `friend_send_message`, `friend_messages`, `friend_mark_read`, `friend_remove`, `friend_update_profile`, `friend_set_avatar`,
`poke_send`, `poke_poll`, `poke_ack`,
그리고 아이디 로그인용 `auth_register`, `auth_link_existing`, `auth_login`, `auth_logout`, `auth_username_state`.
그룹용 `group_create`, `group_join`, `group_leave`, `group_feed`, `group_send_message`, `group_messages`, `group_mark_read`, `group_toggle_hide`, `group_history`, `groups_history_since`, `group_invite_info`.
모든 함수는 `p_user` + `p_secret`(내 브라우저에만 있는 세션 토큰 또는 비밀 토큰)을 확인하고, 위치·기록·메시지는 **서로 `accepted` 인 친구일 때만** 돌려줍니다.

### 아이디·비밀번호 로그인 동작
- `friend_profiles` 에 `username`(소문자, `lower(username)` 유니크)과 `password_hash`(pgcrypto **bcrypt**, `crypt`/`gen_salt('bf',10)`, 4~72바이트) 열이 추가됩니다. 해시는 앱으로 나가지 않습니다.
- `auth_register(아이디, 비밀번호, 닉네임, 기존user_id, 기존secret)` — 기존 값을 주면 **그 프로필에 아이디를 붙여** 친구·채팅·동선을 보존하고, 없으면 새 프로필을 만듭니다.
- `auth_login` → 1년짜리 `session_token` 발급. 이후 모든 RPC 는 기존 `p_secret` 자리에 이 토큰을 넣어 호출합니다(`_urikkiri_ok` 가 secret 과 토큰을 모두 인정).
- `auth_logout` → 그 세션 토큰만 폐기.
- 기존 사용자(`달콩`·`달배니` 등)의 프로필·친구·메시지·동선은 지우거나 바꾸지 않습니다. 아이디를 붙이기 전까지는 예전처럼 비밀 토큰으로 그대로 동작합니다.
- 이미 쓰던 Supabase 프로젝트에는 `supabase_auth.sql` 만 따로 SQL Editor 에서 실행하면 됩니다(여러 번 실행해도 안전).
- v19 기능(프로필 사진·이모지 콕·그룹 위치 숨김·그룹 안 읽음/읽은 사람 수)은 `supabase_v19.sql` 을 한 번 실행하면 켜집니다(여러 번 실행해도 안전).
- v21(1:1 카톡식 안 읽음 숫자·근처 알림)은 **서버 표 변경 없이** 앱 코드만으로 동작합니다(v19 함수가 돌려주는 `unread`·`read_at` 사용).
- v22(지도 스타일 4종)도 서버 변경 없이 앱 코드만으로 동작합니다.
기존 v3 표(`rooms`, `locations`, `location_history`)는 건드리지 않으므로 충돌하지 않습니다.

## 3. 실시간은 어떻게 오나요

- 새 메시지·위치 변화가 생기면 앱이 Realtime **broadcast**로 "새 소식 있음" 신호만 보냅니다(내용 없음).
- 신호를 받은 앱이 서버 함수로 실제 내용을 다시 받아옵니다. 표를 직접 읽을 수 없어도 즉시 반영되고, 남의 대화를 엿볼 수도 없어요.
- 신호가 끊겨도 10초 주기 갱신이 있어서 놓치지 않습니다.

## 4. 폴더 구성

```
index.html            화면 뼈대(시작·지도·친구/채팅 탭·상세 시트·채팅)
styles.css            모바일 퍼스트 스타일
app.js                앱 로직(프로필·친구·위치·동선·채팅·실시간)
config.js             Supabase URL/키, 갱신 주기
supabase_schema.sql   서버 표 + 함수 + 접근 권한 + Realtime 설정
supabase_auth.sql     아이디·비밀번호 로그인 함수
supabase_group.sql    그룹 표 + 함수
supabase_v19.sql      v19: 프로필 사진·콕·그룹 위치 숨김·그룹 안 읽음 함수
sw.js                 서비스 워커(껍데기 캐시, 버전 올리면 기기에 바로 반영)
manifest.json         홈 화면 추가용(PWA)
vendor/leaflet/       지도 라이브러리(오프라인 포함)
icons/                앱 아이콘
preview*.png          화면 미리보기(지도·채팅·동선)
```

## 5. 갱신 배포할 때

1. `app.js`·`styles.css` 등을 고친 뒤 `index.html`의 `?v=` 값과 `sw.js`의 `urikkiri-vN` 을 함께 올립니다(캐시 무효화).
2. `our-map/` 저장소로 push → GitHub Pages 빌드(약 1분) → 새 버전이 기기에 반영됩니다.

## 6. 참고

- 위치 권한은 HTTPS에서만 동작합니다. 거부하면 서울시청 기준 좌표로 표시됩니다.
- 배터리 자동 표시는 안드로이드 크롬 등에서만 열려 있고, iOS 사파리는 '내 프로필 → 배터리 직접 입력'을 쓰면 됩니다.
- 이동 기록은 최근 24시간만 불러오고, 브라우저에는 최근 6시간을 남깁니다.
- 친구를 끊으면 서로의 위치·동선이 보이지 않고, 둘 사이 대화도 함께 정리됩니다.
